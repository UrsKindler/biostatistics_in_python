# NIPALS PCA (No-Imputation PCA for Missing Data)

> **Module Implementation**: [`biostatistics_modules/05b_nipals_no_imputation_pca/`](biostatistics_modules/05b_nipals_no_imputation_pca/)

### Overview
The **NIPALS** (Nonlinear Iterative Partial Least Squares) algorithm calculates Principal Component Analysis (PCA) directly on matrices with missing values (NaNs) **without requiring prior imputation** (such as mean, median, k-NN, or zero imputation).

### When to Use
- When omics datasets have high missingness rates (5-25%) typical in mass spectrometry proteomics and metabolomics.
- When imputation risks distorting covariance structures or introducing artificial cluster artifacts.

### Key Functionality
- Iteratively computes score vectors $t_k$ and loading vectors $p_k$ using only available (observed) values via `np.nansum`.
- Applies orthogonal matrix deflation $X_{k+1} = X_k - t_k p_k^T$.
- Calculates variance explained per principal component.
